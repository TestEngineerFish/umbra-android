### 状态与数据流（`ChatViewModel.swift`）
- 每会话一个 `ConvStore`：blocks、assistantIdx（流式占位下标）、taskMap、oldestId / hasMoreHistory / pagedOnce / historyFailed、loaded。
- VM 级：activeConv、unread Set、devices、previews、draft、quote、chipAction、slashDismissed、ideaBanner、resumeAsks。

**发文字**：乐观气泡 → WS 发送失败标 `failure=.offline`（气泡下「没发出去 · 连接断了」+ 重发 + 检查服务端）→ 发出则画「思考中」三点占位，开 120s 静默超时（任何服务端事件重置，超时换错误卡）。芯片动作以 `【动作名】` 前缀拼进正文；mode 固定 `auto`。

**流式拼接**（:1602-1730）
- delta：`text += text`，thinking=false。
- tool_call：已有正文先挪进轨迹 `💭 文本` 并清空，再追加 `🔧 name(args 前 120 字)`。
- tool_result：追加 `↳ name → preview 前 160 字…`。
- reply：最终 text 覆盖；message_id 作 serverId；meta.citations → 出处 chip；user_message_id 认领我那条；清 assistantIdx。
- reply_cancelled：role=assistant 保留半截并标 interrupted；role=system 换成居中一行。都**替换**占位块。

**认领 id**：文字消息从占位往前找最近一条无 id、未失败的我方消息，已认领过的 id 不再认领；图片按 atts 完全相等认领，认领后释放原图。

**图片发送**：一条最多 9 张；按档位压缩；**逐张顺序上传** `/files/upload`，整数百分比节流刷进度；全部传完才发 WS image 消息；15s 无 `message_saved` 标失败；另起 60s 识图兜底；断点续传（已传不重传）、取消（原图放回待发条）、按代次号丢迟到进度。上传失败四档（太大 / 未登录 / 存储满 / 其他）。

**识图**：`vision_reading{label,n}` → `vision_done{label: none|manyImage|partial|allFailed,…}`。allFailed/超时：错误卡替换气泡；partial：气泡下一行 +「重读这 N 张」（WS `vision_retry`）。

**卡片补发合并**（`ChatCardResend.swift`）：absent→append；open→keep；handled（在更早连接上处理）→reopen；handledOnThisConnection→keep（判断用 wsEpoch）。卡片动作一律**先发出去、发成功才改卡**，没发出吐「没连上」。

## 二、Task（约 2316 行，难度中）

**列表 `TaskViews.swift:18`**（工具页「任务」卡）：顶部「共 N 个 · M 个执行中」；分段「历史 / 计划」（计划只是说明卡）；可收起搜索（title+goal+result_summary）；筛选胶囊带计数：全部 / 执行中 / 待执行 / 完成 / 失败；下拉刷新；可见时 3.5s 轮询；**无左滑无长按**；空态分「真没有」与「被筛选挡掉」（给「清掉筛选」）；三态骨架 / 错误卡 / 离线条。行：短标题、goal 副行（有 name 时）、状态徽标或挂起说明（就绪琥珀、等待灰）、「来自 X」、相对时间、执行中进度条。「已不在」行原位插回只给「知道了」。

**详情 `TaskViews.swift:356`**：四档 内容 / 骨架 / 不存在（一句 +「返回」）/ 失败。内容：头部（标题、goal、徽标、来源、挂起原因卡）→ 总进度 → 两列概要（ID / 来源 / 创建 / 更新 / 步骤 / 失败步骤）→ 步骤（状态图标、`seq. title`、行内 Markdown 说明、错误框、截图最大 330×280）→ 事件时间线彩色圆点 → 结果摘要或失败三段式错误卡。底部：挂起且就绪「接着跑」+「停止」+「复制详情」；非终态「停止」（确认）+ 电脑操作在跑时「看实时画面」+「复制详情」；失败 / 取消「重试任务」或「重新发起」+「复制详情」+ 下一行提示。非终态时 3.5s 轮询。

**VM**：items、details[id]、detailMiss[id]、loadedOnce、firstLoading、gone[id]；列表每次 30 条，失败不清空；每次拉到同步小组件；`openDetails`/`detailEpoch` 丢关页后迟到响应；重试 / 接着跑成功后立即重拉 + 2s 后再拉。

**规则**
- `TaskDetailRules`：非终态 = running/pending/suspended；只有 404 算不存在；档位优先级 不存在 > 有内容 > 失败 > 骨架；轮询：不存在停、没拿到继续、拿到看非终态。离开 suspended 清掉「接着跑失败」行。channelLabel 空白视为无。
- `TaskRetryRules`：2xx→ok；404 或 state=missing→missing；409 state_conflict → wrong_status / nothing_to_retry / operate / not_retryable(detail)；0→offline；≥500→serverError；其余 unknown。按钮：failed 或 cancelled 且失败类别 asBefore 且未锁死；`executor=="operate"` 给「重新发起」（goal 填进聊天不自动发）。cardAction：已不在→无；非失败→查看结果；有 topup→去充值；noRetry→查看结果；其余→重试 / 重新发起。文案与 PC 逐字一致（`TaskRetryCopy`）。
- `TaskSuspendRules`：两档 设备 / 能力；就绪优先看 ready_reason；只有 `no_capability` 是能力档。设备念法：一台→名字；多台→「A 等 N 台设备」；无名→「能做这一步的设备」（去书名号）。能力最多列 2 项否则「A、B 等 k 项」。步号 <1 或 null 念「这一步」。接着跑出现：`status=="suspended" && resume_ready`。需人处理（角标）：failed / error / 挂起且就绪。接着跑结果：not_ready（本地撤就绪）/ wrong_status / missing / offline / 5xx / unknown。
- `TaskStepRules`：截图 URL 只认单个 `/` 开头的相对路径（拒 `//` 与 `\`）或同源 http(s)，无 userinfo。事件点色：payload.status failed→红 done→绿 suspended→黄；再看 type result/milestone→绿 locate→黄；其余灰。
- 文案模板 `TaskSuspendCopy.swift`。

**iOS 特有**：Live Activity / 灵动岛 → Android **无法实现**灵动岛，改用进行中通知（Android 16 `ProgressStyle` / Live Updates）；小组件 → Glance。

**规则**：
- `InspLocalRules`：本机 dirty 且比服务端新 → 保留本机正文但收整数 id / 整理 / 调研字段；本机删除时间晚于服务端更新 → 不加回；远端墓碑删本机（本机 dirty 且更新的除外）。排序：id ≤ 0 最前，其余 id 降序，同 id 按 updated_at_ms 降序。新建没填标题 `organize_status=pending`。换账号：不带过去清空；带过去只留 dirty 并重置临时 id。
- `InspirationWriteRules`：保存失败留在页面（「没存上，内容还在，稍后再点保存」）；删除 nil→「没删掉」、0→「这条已经不在了」并退页、>0→「已移入回收站 · 保留 30 天」；编辑只报变化字段，无改动提示「没有改动」；带 id 找不到 → gone，绝不新建；改状态成功不吐司。
- `InspirationIntentRules`：未登录 / 内容为空 / 未配置 / 离线 / 不确定 / 被拒 / 服务端错 / 失败各一 key。

## 五、Remote（远程控制，iOS 只做控制端，约 3468 行，难度最高）

**入口**（都汇到 `RemoteLauncher.launch`）：设备详情「远程」组三行（远程查看 / 远程控制 / 看一眼）+ 会话记录（30 天 20 条）+ 本月中继用量；设备会话导航栏显示器菜单；求助卡「实时接管」（source=locate, ask_id）；任务详情「看实时画面」（source=task, run_id，只看档）。
门 `RemoteEntryRules.gate` 顺序：离线 → 没上报 remote → !available → 想控制但 control==false → 看一眼但缺 snapshot 技能 → 非会员（跳商城）。

**会话页**：全屏层。视频（aspectFit）或快照；顶部工具条（结束、路径标识 直连 / 中继 / 快照、显示器切换、画质 auto/hd/smooth/saver、剪贴板发送 / 取回、键盘、文件、刷新、复位缩放、安全短码、升降档、收起）自动隐藏；locate 控制档有「交还给秘书」；修饰键栏 ⌘⌥⌃⇧（点一次 / 锁定 / 松开）+ Esc、Tab、方向、Del；蒙层（等待同意 / 连接中 / 重连中 / 窗口受保护 / 已结束）；PIN 面板（6–8 位）；短码核对。
手势：单击左键；双击 n=2；双指单击右键；长按松手右键；长按后拖=拖拽；单指拖=触控板移动；双指拖=滚轮；捏合本地缩放 1–5（不发送）。隐形输入框接键盘，组字期间不发。

**文件面板**：「下载 / 桌面」两目录；推送文件；进度列表；拉回交系统分享；失败可续传；中继时提示计流量。

**信令**（全走 `/ws/chat`，`rc_` 前缀分流）：
1. 上行 `rc_request{request_id, device_id, mode:view|control, source:manual|snapshot|locate|task, run_id?, ask_id?, client_id, client_name, client_kind}`。
2. 服务端先推 `rc_state{awaiting_consent}` 再回 `rc_created{request_id, session_id}` → 拿到 sid 前缓存最多 16 帧，之后只放 sid 匹配的。`rc_error{code,message,request_id?}` 按 request_id 认领；不带 request_id 的「没开远程控制」等待期间也认。
3. 同意后 `rc_state{state:connecting|active|ended, session_id, mode, source, run_id, host_device_id, host_name, unattended, relay_allowed, started_at_ms, reason, notice, ice_servers[{urls(串或数组), username, credential}]}`。
4. **被控端是 offerer**：建屏幕轨 + 两条 DataChannel（`rc` JSON、`file` 二进制），发 `rc_offer{session_id, sdp}`。
5. 控制端 answerer：unifiedPlan、maxBundle、rtcpMux require、gatherContinually；关音频；setRemote → 补加缓存候选 → createAnswer → setLocal → `rc_answer{session_id, sdp}`。
6. Trickle ICE 双向 `rc_ice{session_id, candidate, sdpMid?, sdpMLineIndex, usernameFragment?}`（ufrag 从 candidate 串 `ufrag` 后取）。
7. 连上后 `rc_stats{session_id, connected:true, path:direct|relay, relay_bytes, rtt_ms}`，之后每 10s 报一次。选中 pair 任一端 relay 即中继。
8. `rc_mode`（升档要再同意，回答经 rc_state，可能带 notice upgrade_declined / no_control_permission / busy；降档立即）、`rc_end`、`rc_attach`（WS 重连接回，宽限 30s）、`rc_handback`（locate）。
9. 新 ice_servers → setConfiguration；ICE restart 由被控端发起。

**DataChannel `rc`**：控制端发 输入 `{t:move|down|up|click|wheel|key|text, x,y(0–1 四位小数), b:0|1|2, n, dx,dy, code(W3C), down, mods:["cmd","alt","ctrl","shift"], s, display}`；命令 `display{id}`、`quality{level}`、`clip_send{text}`、`clip_get`、`pin{pin}`、`ping{ts}`（5s）、`files_list{dir}`、`file_get{id,dir,name,offset?}`、`file_put_begin{id,name,size}`、`file_put_end{id}`。被控端发 `displays{items,current}`、`clip{text}`、`pong{ts}`、`need_pin`、`pin_result{ok,locked_until_ms}`、`protected{app}`、`unprotected`、`denied{reason:blacklist|local_input|view_only, app}`、`idle_downgrade`、`files{dir,items[{name,size,mtime_ms}]}`、`file_begin{id,name,size}`、`file_end{id,ok,error}`、`file_put_result{id,ok,error}`。
**DataChannel `file`**：每块 = 4 字节大端 id 长度 + UTF-8 id + ≤64KB 数据；bufferedAmount >1MB 每 20ms 等；单文件中继 100MB / 直连 500MB；id `android-<序号>`。
**安全短码**：两份 SDP 各取第一行 `a=fingerprint:`，算法名小写、十六进制大写；按 UTF-8 字节序排序 `|` 拼接 → SHA-256 → 前 4 字节大端 mod 10000 补 4 位。无人值守首次连某设备核对一次，按设备本地记。
**快照降级**：connecting 后 15s 没连上 → 关 PC 走快照：`POST /remote/sessions/{sid}/snapshot {display?}`（20s）→ `{url,width,height,display,at_ms}`，GET 取图（只认同源，带 Bearer），每 2s 一张；快照不许输入。`source=snapshot` 全程不建 WebRTC。等同意本地兜底 35s；ICE 断开宽限 30s（`ice_lost`）；切后台保留 30s。
**其他**：无人值守先本机认证再弹 PIN；蜂窝默认 saver；保险箱复制出的敏感剪贴板不发送。
**几何**：视图坐标逆缩放平移、减 aspectFit 黑边 → 帧内 0–1，落黑边返回 null；平移夹紧；以捏合中心缩放。触控板增益 <150pt/s 为 1、1200pt/s 为 3、中间线性。move 60Hz 节流；长按拖拽阈值 8pt。ASCII→W3C code 映射，需 Shift 的自动补；非 ASCII 合并成一条 text。
**Android**：`io.github.webrtc-sdk:android`（已在版本目录）或 stream-webrtc-android；`SurfaceViewRenderer` + EglBase；不建本地音视频轨；BiometricPrompt（STRONG | DEVICE_CREDENTIAL）；ConnectivityManager.NetworkCallback。

## 六、Tool（工具页，约 453 行，难度低）
