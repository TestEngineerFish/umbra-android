## B. 导航

### 核心
- `Navigation/RouteRules.swift`：路由表 `UmbraRoute`（16–115）、分区 `area`、`needsLogin`（160–179）、`tab`、`isVaultSubtree`、`isEditor`（212–229）、`UmbraTab`（245–279）、跨 Tab 跳转 `UmbraJumpRules`（294–309）、深链（313–361）。全部穷举 switch 不写 default → Android 用 sealed interface + 穷举 `when`。
- `Navigation/Router.swift`：唯一状态源。`tab`、`paths: [Tab: [Route]]`、`sheets`（多层）、`alert`（一格）、`toast`。API：go / back / back(ifShowing:)（异步回包后只在栈顶仍是这页时才退）/ root / jump / present / popSheet / closeSheets / confirm / showToast（无动作 1.8s，带动作 3s）。再点当前 Tab 清栈回根。
- `AppShell.swift`：Tab + 每 Tab 一条栈；推入页隐藏底栏；路由拦截只在 `UmbraRouteView` 一处：`route.needsLogin && sessionGuard.locked` → 画 `UmbraNeedLoginView`。

### 门与拦截
- 门 `UmbraGate`：checking / open / login / register / sessionInvalid（判据见 01 文档 §2）。

### 跨 Tab 跳转与深链
- jump 三档：目标就在眼前 → reveal（只切 Tab）；目标 Tab 栈里有编辑页 → askFirst（「放弃正在写的内容？」按钮「留在这里 / 放弃并前往」，后者红）；其余 → replace（清栈、落根、推目标）。
- 深链见 01 文档 §6。门在问时攥着；门开就跳；门关时 needsLogin 页丢弃，本地页照跳。
- 通知：提醒分类 `umbra.reminder` 两动作 `done`（幂等完成）/ `snooze`（再等 10 分钟）；前台也弹；点本体 → remDetail；执勤推送 → 定位消息再 chatThread(conv)。

## A. 功能页

### 我 · 首页（MeViews.swift:19）
- Hero：smartphone 图标；名字=设备名；徽标「此设备」；副行=服务器 host:port（等宽）。
- 分组：账号（「账号」值=显示名或邮箱 / 未登录 /「商城」）；设备（「设备与能力」值 N 台）；助手（记忆 / 知识库 / 执勤）；设置（连接 / 通知 / 通用 / 回收站 / 关于）。
- 连接行四档：已连接 check（success 色）/ 连接中 spinner / 未连接 xCircle / 登录失效 alertTriangle（其余 muted）。下拉刷新 `GET /devices/all`。

### 设备与能力 / 设备详情 / 能力
- 列表行副文「平台 · 在线/离线·最后在线 · N 个 provider」。
- 详情：Hero monitor + 在线徽标；远程入口组；「信息」（平台、设备 ID 等宽点复制、最后在线）；「能力」各 provider（→ meCaps）；「会话」开关「允许在这里直接吩咐设备」（全局 allowDeviceSend）；⋯「从联系人列表移除」→ `DELETE /devices/{id}`。
- 能力页 `GET /capabilities`，每 provider 一组「provider · 设备名」；拉失败与为空分开说。

### 连接 / 通知 / 通用 / 关于
- 连接：服务端地址只读；状态行 + 原因；动作行：凭证被拒「重新登录」，否则「重新连接」。
- 通知：权限状态 +「去系统设置」，不做分类开关。
- 通用：界面语言（中文 / English / 跟随系统）；外观（浅 / 深 / 跟随，`umbra.appearance`）；发图画质（saver / standard / clear / origin，像素数取 `/settings.image_tiers`，写 `PUT /settings {image.quality.<purpose>}`）。
- 关于：版本 `versionName (versionCode) · Android`；客户端 ID 点复制。

### 账号（AccountViews.swift:41）
- 进页：`/auth/me` → `/credits` → `/membership`（带 storage 就用，否则 `/storage`）。
- 未登录：一行「重新登录」+ lastRefreshError。
- 已登录自上而下：Hero（名字、邮箱、注销留期徽标）→ 存储条幅（到期超出不可关带「续费会员」；warn 可关带「不再提示」`storage.warnBannerSilenced`）→ 会员组（档位 · 来源；到期日 · 剩几天；「5 小时额度」「本周额度」百分比 ≥100 红 ≥80 橙；会员折扣；自动续费开关；续费 / 开会员外链）→ 商城 → 积分（可用、去充值、最近 5 条）→ 邮箱未验证组（重发：cooling / sent / already_verified）→ 账号组（显示名可改、邮箱、ID 点复制、注册于、服务器）→ 使用记录 → 存储摘要卡 → 设备「登录设备 N 台」→ 密码「改登录密码」（OIDC 不画）→「注销账号」红（OIDC 不画）。
- ⋯「登出这台设备」确认后 logout。写失败吐司三档：连不上 / 会话失效 / 服务端原话。
- 改密码：三格密码框（高 40 圆角 10 bg 底 1px border）；端上比两次一致；最少 10 位；400 → 错误卡「当前密码不对」；回 logged_out:N。
- 登录设备：只读「登录于 / 最后活跃 yyyy-MM-dd HH:mm」。
- 注销：整屏；一字不差打出邮箱（不分大小写）才能按实心红钮；留期 30 天。

### 管理存储（StorageView.swift）
- 顶部用量（used/limit + 档位芯片 + % + 6 高进度条）；四组 聊天与附件 / 知识库 / 保险箱（一行不可列）/ 回收站，组内按大小倒序，末尾「其余 N 项」。
- 左滑：文件、知识库文档「删除」；回收站「找回」+「彻底删除」。⋯ 清空回收站。
- 知识库文档删除先取 blob_sha 再带 If-Match；`trash/restore` 回 restored:0 不算成功。
- `StorageRules`：1024 进制；<1MB 显示 KB；≥100MB 取整；≥1024MB 显示 GB 两位小数去尾零；档 ok/warn/critical/full → normal/warning/danger；到期超出 = 免费档且 used>limit。

### 商城 / 道具历史（ShopView.swift）
付钱：`/shop/checkout` → 外链 pay_url → 每 3s 轮询订单，兜底 15 分钟。分组：等待支付 / 我的 / 我的道具 · N 张可用（快过期副行 ⚠）/ 会员 / 积分充值 / 重置卡与加量包。

### 记忆（MemoryViews.swift / MemoryRules.swift）
- 列表：第一组「告诉秘书要记住什么」（橙字，sheet）+「从其他 AI 导入」，发出后该行就地变「转圈 + 整理中… + 原话」；开关组（`/settings` 的 memory.generate 默认 true、memory.searchChats 默认 true、memory.sensitive 默认 false）；「你 / 话题 / 领域 / 人物」分组带条数；页脚「N / 200 条」；「+」满 200 禁用；⋯「全部清空」。
- 详情：26/650 大标题 +「分类 · 最后更新」；一句话卡；「详情 · N 条」。固定两条（preferences / profile）只能清空不能删。
- 编辑：新建时分段选分类；固定条标题与一句话只读；冲突 409 → warning 卡「载入新版」/「覆盖保存」（覆盖再确认）；导入页先给提示词卡「复制提示词」再粘贴，上限 20000 字。
- 规则：you = preferences/profile；area、person 各成组；其余 topic。时间：今天 / 昨天 / N 天前 / MM-dd / yyyy-MM-dd +「更新」。会话一换（服务器地址+令牌摘要）先清空再读。

### 知识库（KnowledgeViews.swift / KnowledgeRules.swift）
- 库列表：folder 图标 + 名称（15.5/560）+「N 份 · M 份处理中 · K 份失败」（有失败 dangerText）+ chevron，行最小高 48；「+」alert 输入库名。

### 执勤（DutyViews.swift 等）
- 首页：① 总开关 + 档位（save / essential / stopped 一行橙字）+ 通知被拒「去设置」+ 暂停（hour / today / week / forever，paused_until_ms 超十年当「直到恢复」）/ 恢复；首次打开先知情确认，写 `{consented, enabled}`，开关显示 = enabled && consented。② 秘书的提议卡：好 / 不用 /「现在看一遍」。③ 早报卡：开关、时间、工作日/每天、城市、天气/提醒/任务三开关、邮件、「秘书判断」、上次结果、「试一次」。④ 执勤表：点行编辑，开关独立热区，末行「新建」→ 选预设或「自己定」。⑤ 流程区只读可一键跑。⑥ 关注区：重要度 1–5、只进早报 / 恢复 / 结束 / 删除。⑦ 规矩：静默起止、每天最多主动说几次 1–10、预算 5–40%（5 一档）。⑧ 最近 14 天日志按天分组，点看「为什么」，底部「全部日志」。
- 编辑：本地草稿保存时整份写回；触发 recur / at / window / interval；动作 say / task / flow（workflow 置灰写原因）；规矩：秘书判断、优先级、冷却 0–1440 分、每天点数上限 0–50、遵守静默；⋯ 删除；保存前 `DutyDraft.problem()`。
- 日志页可按条目筛；流程页：摘要、一键跑、最近运行、节点拓扑序；运行详情逐节点状态。

## D. 多语言
- `AppLanguage`：system / chinese / english（`appLanguage`）；跟随系统时 zh 开头→中文，en→英文，其余中文。改了偏好整棵视图重建。
- `Localizable.xcstrings`：sourceLanguage zh-Hans，1495 key，只有中英。1043 个点分 key（duty 398、remote 162、chat 126、kb 73、presence 53、reminder 52…）；404 个中文字面 key 无英文。格式符 `%@`、`%lld`、`%1$@` 等。
- **大量文案写死在 Swift 里**（MeViews、AccountViews、AuthScreen 大部分），英文模式下仍是中文。
- Android 方案：脚本把 xcstrings 转成 `values/strings.xml`（中文默认）+ `values-en/strings.xml`；点分 key `.`→`_`；中文字面 key 生成 `s_<sha1 前 8>` 并出映射表；`%@`→`%s`、`%lld`→`%d`，多参数补位置；转义 `' " @ ? & <`。语言切换用 `AppCompatDelegate.setApplicationLocales`（per-app language，Android 13+ 系统设置里也能切）。
