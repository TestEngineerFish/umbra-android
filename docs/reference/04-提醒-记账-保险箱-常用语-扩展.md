# C. 保险箱（F/Vault）

## C1 加密（VaultCore.swift:15-117）——逐字节
1. 记录 `VRecord` = 服务端 blob：`{"v":1,"kdf":"pbkdf2","salt":"<b64>","verifier":"<hex>","enc":"<v1:...>"}`，**键序固定**（iOS 字符串拼接，:1153）。salt 16 随机字节，标准 Base64 带 `=` 不换行。
2. **Secret Key**：生成 16 随机字节 → RFC4648 Base32 大写无填充 26 字符，每 5 字符一组 `-` 连，前加 `U1-` → `U1-XXXXX-XXXXX-XXXXX-XXXXX-XXXXX-X`。
   解码 `decodeSecretKey`：转大写 → **只保留 `[A-Z2-7]`** → 若以 `U1` 开头去掉 → Base32 解码（不认识字符跳过）→ 取前 16 字节。
   ⚠️ **两端都有的怪行为**：过滤时 `1` 已被删，`U1-…` 变 `U…`，`U1` 前缀永远不成立，`U`（值 20）作为最前 5 位被一起解码，得到的 16 字节**不是**生成时的随机字节。两端一致所以互通，**Android 必须照抄，不能修**。
   Base32 解码：`value=(value<<5)|idx; bits+=5;` 每满 8 位输出 `(value>>(bits-8))&0xff`，`bits-=8`。
3. AUK：`pwKey = PBKDF2-HMAC-SHA256(password UTF-8 字节, salt, 600000, 32)`（**不做 NFC/NFKC**）；`sk = decodeSecretKey(sk)` 16 字节；`AUK = HKDF-SHA256(ikm = pwKey‖sk 48 字节, salt = 同一 salt, info = "umbra-vault-auk-v1", 32)`。kdf 只认 pbkdf2。
4. 校验：`authHash = HKDF-SHA256(ikm=AUK, salt, info="umbra-vault-auth-v1", 32)`；`verifier = hex小写(SHA256(authHash 原始 32 字节))`。解锁比 `verifier == record.verifier`。
5. 字符串密文：AES-256-GCM，nonce 12 字节随机，tag 16，无 AAD；格式 `"v1:" + b64(iv) + ":" + b64(tag) + ":" + b64(ct)`（**tag 在 ct 前**）。解析按 `:` 最多切 4 段，第一段必须 `v1`。Java 输出 `ct‖tag`，需拆开。
6. 整份快照 `record.enc = aesEncrypt(AUK, JSON(VSnapshot))`（**用 AUK，不是 VaultKey**）。快照 `{v:1, vaults:[{id,name,owner,icon,order,keyWrapped}], data:{<vid>:{types:[{id,name,icon,order}], items:[VItem], attachments:{attId: base64}}}}`。数字字段是 Double，宽松解析。
7. VaultKey：每库 32 随机字节，`keyWrapped = aesEncrypt(AUK, vk 原始 32 字节)`，只用于附件。
8. 二进制附件（`GET /files/{fileId}`）：裸字节 `iv(12)‖tag(16)‖ct`，用该库 VaultKey 解。
9. 本机建库：主密码 ≥6 位；随机 salt；生成 SK；生成 vk；库「我自己」icon `🧑` owner `self` id `"v"+18 位 hex`；内置 4 类型 登录🔑 / 银行卡💳 / 证件/文档🪪 / 安全笔记📝，id `"t"+18 位 hex`（rid = 前缀 + 9 随机字节 hex）。记录 id `"i"+10 位`，节点 id `"n"+18 位 hex`。

## C4 同步（VaultSyncRules.swift + VaultCore.swift:463-1243）
- `GET /vault/sync?have_rev=` → `{exists, rev, blob}`（401/403 提示去登录；404/其它回落缓存）；`PUT /vault/sync {blob, baseRev, deviceId, force}` → `{ok, rev}` 或 `{conflict:true, rev, blob}`。
- 锁着时用拉到的那份（`pullAdopt`）：已解锁→合并；无缓存→采用云端；缓存读不出或解不开→采用云端不写盘；pending≠true→采用云端；verifier 不同且用户选「以云端为准」→云端；否则保留本机。
- 解锁解哪份（`unlockPick`）：认定云端时先试云端；本机能解用本机；没认定云端而云端能解 → 提示「两份只能留一份」；都不行 → 密码错误。
- 合并：库和类型并集；记录 **revision 大者胜，相等 updatedAt 晚者胜**；附件字节并集。`mergeGate`：解锁代次变过回包作废；非冲突回包而 syncRev 已不是基线作废；云端 rev = 基线无新东西。verifier 不一致 → keyMismatch「锁定并重新解锁」。
- 推送：最多 3 次，每次重新编码；**只有第 3 次且前面冲突都合并成功才 force=true**；合并失败就停。推前 verifier 必须等于解锁时验过的；剔除没被引用的附件；**清空所有内联附件 base64**。先写本机缓存 pending:true 再推；推成功且推的就是最后落盘那份才标已同步。
- 离线 / 未登录完全可用。

## C5 TOTP（RFC 6238）
裸 Base32（去空白和 `-`）或 `otpauth://...?secret=&digits=&period=&algorithm=`（参数名不分大小写）。默认 6 位 30 秒 SHA1；位数只收 6~8，周期 1~86400；SHA256/SHA512 其余 SHA1。显示 6 位写「123 456」，倒计时 `period − t%period`。

## C6 密码生成器
默认长 20（8~40），大写、数字、符号开，「避免易混」开。小写 `abcdefghijkmnpqrstuvwxyz`；大写 `ABCDEFGHJKLMNPQRSTUVWXYZ`；数字避免易混 `23456789` 否则 `0123456789`；符号 `!@#$%^&*-_=+?`；关掉避免易混再追加 `ilo01O`。每字节对池长取模。**不保证每类至少一个**（PC 保证，两端不同）。

## C7 强度评估（PasswordStrength.swift:139-211，与 PC 共用 61 条夹具）
长度按码点。classes：a-z / A-Z / 0-9 / 其它。从左到右每位置依次试：a 常见词（words 表，leet 归一，前缀最长）→1；b 日期 YYYYMMDD（1900-2099）→2；c 手机号（11 位 `1[3-9]`）→2；d 年份 19xx/20xx→1；e 键盘行（正或倒，≥4）→1；f ASCII 连续升降（≥3）→1；g 同码点重复 ≥3→1；h 2~4 码点片段连续 ≥3 次→片段长度；都不中吃 1 个→1。权重和 = eff。档：len<8 或 eff<8 弱；(eff≥12 且 classes≥3) 或 (eff≥16 且 classes≥2) 或 eff≥20 强；其余中。pct = clamp(round(eff×5), 12, 100)。三张表 :69-95 逐字照抄。

## C8 锁与生物识别
- 软锁（AUK 在内存，只验身份）/ 硬锁（清 AUK、快照、vaultKeys、附件明文）。
- 自动锁定：墙钟；只有「关→开」那刻清零；保险箱内动作 touch；每 5s 巡检 + 回前台判一次；0 = 不锁；墙钟回拨 >60s 按到点；上锁退掉保险箱子页。时长 1/5/10/30 分钟。
- 生物识别取回主密码：开启前先校验主密码 + 刷一次生物识别；取回不允许退回设备密码；读失败视为生物数据变了，作废并清。失败分类 cancelled / lockout / invalidated / unavailable / failed。进锁屏 420ms 后自动刷一次；选过「用主密码」或主动上锁后不自动弹。首次用主密码解锁成功后问一次要不要开。
- 后台遮罩 → Android 保险箱页 `FLAG_SECURE`（还能防截屏）。

## C9 剪贴板
保险箱复制一律走敏感入口：Android `ClipDescription.EXTRA_IS_SENSITIVE`（33+），60s 后若剪贴板仍是我们放的那份（比 `ClipDescription.getTimestamp()`）则清空。敏感值显示 8s 后自动遮回；复制后行内「已复制」1.5s。常用语 `{clipboard}` 遇敏感值展开为空。

## C10 页面
- 首页：锁屏态（96 识别图标、主密码框、Secret Key 框（本机没有确认过的 SK 时才出）、两种错误卡（连错 3 次改提示 SK 恢复）、「恢复 / 建库」）；解锁态（自动锁定条幅、离线条、身份库卡、搜索、分类芯片 全部/收藏/各类型、体检一行；按分组的列表，左滑「删除 / 复制密码（只有一个密码时）」，长按菜单；空态；＋、⋮ 面板 体检 / 生成器 / 分组 / 身份库 / 回收站 / 导入 / 设置；下拉 = 真同步）。
- 记录页：节点卡、TOTP 行、图片全屏、查找条（n/m 上一个下一个）、编辑、收藏。
- 编辑：**自动保存**（停手 900ms 落一笔，离开前落掉）；新建一律是画布记录（一个账号节点）；旧记录可增删控件、上下移、就地生成密码。
- 工具：生成器、体检、分组（只读 + 移动）、身份库（只读 + 切换）、回收站、导入（说明）、建库、恢复、SK 查看、设置（自动锁定 / 遮罩 / 生物识别 / 立即同步 / 忘掉本机数据）、改主密码（说明，要在电脑上做）。

# D. 常用语（F/Me：PhrasesView / PhraseModel / PhraseSyncRules / PhraseVars）
- 列表：头部「N 条」+ 同步按钮（三态，未登录不画）；行：名称、关键词胶囊、首行预览、右侧常驻复制钮（复制后勾 2s）；左滑「删除（确认）/ 编辑」；长按拖动排序；底部明文存储警示；下拉 = 同步。
- 编辑：名称、标签（已有关键词芯片预选）、内容（最小高 180）；必填缺了点保存给 toast，按钮不置灰。
- 模型 `Phrase{id(UUID), name, content, keyword?, order, updatedAt(ms), orderUpdatedAt?(ms)}`，墓碑 `{id, deletedAt}`；本地 `phrases.local {items, deleted}`，`phrases.syncedAt`。
- 同步 `POST /phrases/sync`：keyword 空**不带键**；orderUpdatedAt 总带（缺取 updatedAt）。服务端内容按 updatedAt、位置按 orderUpdatedAt LWW。本地版本号每改 +1，回包时版本变过就丢回包再推，最多 4 轮。盖戳：新加两戳都 now；内容变只盖 updatedAt；order 变只盖 orderUpdatedAt；0 当没记过。新建 order = max+1；拖动后重排成下标。未登录不同步。
- 占位展开：正则 `\{(date|time|clipboard)(?::([^}]*))?\}`；格式 `YYYY|SSS|ddd|YY|MM|DD|HH|mm|ss`；公历本机时区；`ddd` 中文星期「日一二三四五六」；只扫一遍；`{date:}` 空格式回默认；`{clipboard:x}` 原样保留；剪贴板只在用到时读一次；敏感值展开为空；toast 三档。
