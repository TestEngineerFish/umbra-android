# 答复实现侧 · Android 平台差异（回第 199 号）

> 设计侧 · 2026-10-17 · 本地镜像（原件在 Claude Design 项目 Umbra_design 根目录，etag 1792221016422837）
> 出图：Claude Design 项目里的 `Android 端/Pages/平台差异.dc.html`（锚点 #2 / #9 / #10 / #11），宽度按 360dp 画，数值即 dp。
> 总体做法（复用 iOS 稿与 token、只换平台交互层）认可。下面逐条裁定。

## 先补一条全局规则

- **点击热区 Android 上取 48dp**（iOS 是 44pt）。视觉尺寸不变，用透明外框撑，同 iOS 的做法。
- 字体走系统默认（不打包字体）。字重映射：400→Normal，560→Medium(500)，600 / 650→SemiBold(600)；机型缺 600 时退 Bold。

## 逐条

**1 底栏** —— 照默认，加三点：
- 不要 M3 选中胶囊指示器（activeIndicator），选中只靠橙色图标 + 加粗描边 + 橙色标签。
- 去掉点按水波纹，保持和 iOS 一样无按压形变。
- card 底色延伸进手势条 / 三键导航区（edge-to-edge），不留系统黑条。

**2 根页大标题** —— 照默认（27/650 随列表滚走），**另加顶栏渐显**，规格见出图 #2：
- 滚动 0：顶栏 54 高，透明、无字。
- 滚动 14→58 之间：顶栏 card 底、底边 1px borderSoft、标题 17/600 三者同步线性渐显（与 iOS 同区间）。
- 根页标题左对齐，左距 16；推入页顶栏一开始就是实底。
- 不用 M3 LargeTopAppBar，自己用 LazyListState 的滚动偏移驱动 alpha 即可。

**3 返回** —— 照默认。箭头用 Lucide `arrow-left`，22、stroke 2，热区 48。推入页标题跟在箭头后，单行截断。

**4 左滑操作** —— 照默认。补充：拖到底也不自动执行；删除类按钮点了仍走二次确认（「删除后会移入回收站，保留 30 天」）。长按菜单保留，作为同一组操作的第二入口。

**5 锚定小弹框** —— 照默认。规格：card 底、圆角 12、阴影 `0 8px 24px rgba(0,0,0,.13)`、行高 48、最小宽 180；菜单里的删除项文字用 dangerText。

**6 底部操作表 / 选择器** —— 照默认。把手 36×4、圆角 999、色取 border；顶部圆角 26。

**7 确认弹窗** —— 照默认（右对齐、AlertDialog），改一处：
- **破坏性最终动作用实心红胶囊按钮**（danger 底、白字、高 40），不用 dangerText 文字按钮——规范里实心红就是留给这一处的。左侧「取消」仍是正文色文字按钮。
- 非破坏性确认用 orangeText 文字按钮。按钮文案照旧：动词 2–4 字，不写「确定」。
- 圆角 28 可以。

**8 日期 / 时间** —— 确认：Android 上也用 `UmbraDateTimePanel` 自绘，走底部弹层，不用 M3 原生日期选择器。

**9 任务进行中通知** —— 按出图 #9 的四个状态实现：
- 小图标：单色字标「U」（状态栏要求单色）；accent 色 `#E8590C`。
- **执行中**（常驻、不可划掉）：标题 = 任务名；正文 = `第 3/8 步 · 打开价格页并截图`；进度 = 已完成步数 / 总步数，Live Updates 下用分段样式每步一段；头部用系统计时器（`setUsesChronometer`）真走秒；动作只有「停止」，点了拉起 App 内的停止确认。点本体进任务详情。
- **需确认**（常驻，只提醒一次）：标题 = `任务名 · 等你确认`；正文 = 秘书的问题原文，2 行截断；进度条停住转 warning 色，计时停；动作「去确认」「停止」。
- **失败**（转普通通知，可划掉）：三段式拆进三个槽——标题 = 发生了什么（`第 2 步中断：模型没有响应`）；正文 = `任务名 · 为什么`；动作 = 任务详情错误卡的前两个按钮（如「重试任务」「去充值」）。
- **完成**（普通通知，可划掉）：标题 = 任务名；正文 = `全部完成 · 耗时 4分08秒`；动作「查看产出」。App 在前台且正停在该任务详情时不发。
- 状态栏胶囊只放百分比（`38%`），需确认时换「待确认」。
- 渠道两个：「任务进行中」（低打扰、无声）与「任务结果」（默认级别）。

**10 桌面小组件** —— 按出图 #10：
- **任务**：最小 = 默认 2×2，排版同 iOS 小号；可拉宽到 4×2，环放左，右侧补当前步与用时；不往高拉。
- **今日提醒**：最小 = 默认 4×2，放 2 行 +「还有 N 条」（正好 3 条时直接显示第三行）；可拉高到 4×4，按高度逐行加，最多 6 行。
- 圆角交系统裁切（Android 12+ 系统半径），不自绘 32 圆角、不加阴影；内边距 14；card 底随系统深浅色。超过 10 分钟没更新，右上角显示「更新于 HH:mm」。
- 小组件不做写操作，同 iOS。

**11 说明页** —— 页名「**小组件与快捷方式**」。「我」页入口副标题：`任务 + 今日提醒 · 长按图标记一笔`。正文与分组见出图 #11：
- 导语沿用 iOS 原句。
- 「怎么添加」三步：长按桌面空白处，点「小组件」。有的手机叫「小部件」或「卡片」 / 找到 Umbra，挑「任务」或「今日提醒」，拖到想放的位置 / 放好后长按小组件，拖边框可以调大小。
- 「长按图标记一笔」两步：长按桌面上的 Umbra 图标，弹出「记一笔」「记灵感」，点一下直接进对应页面 / 按住其中一项拖到桌面，会变成一个单独的图标，以后一点就到。脚注：直接落在记一笔页，不用先过主屏。
- 快捷方式图标：自适应图标，bg 底 + text 色线性描边（记一笔 = 加号，记灵感 = 灯泡），不用橙底。

**12 自动填充** —— 照默认。文字定为：
- 已解锁：标题 = 条目名称（如「运营后台」）；副标题 = 用户名，明文不遮盖。密码永远不进建议条。
- 已上锁：只出一条，标题「Umbra 密码保险箱」，副标题「解锁后选账号」，点了拉起解锁页。
- 解锁页沿用保险箱锁屏态，那句改为「解锁后才能填充。生物识别通过即可，不用打开 Umbra。」
- 键盘内联建议（Android 11+）只显示标题。

**13 生物识别** —— 统称「生物识别」，图标照默认沿用 faceId 那颗。文案替换：
- 设置开关：`用生物识别解锁` / `仍需主密码作为最终凭证`
- 锁屏按钮：`生物识别解锁`；进行中：`识别中…`，副文 `按系统提示验证`（不写「看一下屏幕」，指纹机不成立）
- 失败：`生物识别没通过` / `系统没能识别，可能是没对准或超过了等待时间。点一下识别图标再试一次，或者输入主密码。`
- 多次失败被系统暂停：`生物识别暂时停用` / `失败次数过多，系统暂停了识别。用主密码解锁。`
- 未录入：`这台手机还没录入指纹或面部` + 按钮「去系统设置」
- 已关闭：`生物识别已在保险箱设置里关掉`
- 解锁成功 toast：`已解锁`
- 系统弹出的验证框由 BiometricPrompt 画，标题填「解锁密码保险箱」，取消键文字填「用主密码」。

**14 toast** —— 照默认（84 / 32），补两点：
- 距底在 84 / 32 之外再加系统手势区 inset。
- 不用 M3 Snackbar。保险箱复制时：剪贴板项打上敏感标记（`EXTRA_IS_SENSITIVE`），系统预览会遮盖；Android 13+ 系统自己会弹复制提示，但我们的 toast 仍要出，因为要写明「60 秒后清空剪贴板」。
