**1 平台字面替换** —— 认，三句照你写的落：
- `用 Face ID` → `用生物识别`
- `用 Face ID 确认是你` → `用生物识别确认是你`
- `从 iPhone 推一个过去` → `从手机推一个过去`

以后同类替换（Face ID / Touch ID → 生物识别，iPhone → 手机）照这条类推，不用再单独报。

**2 拉回来的文件 · 存储** —— 形制和三句都认：点「存储」弹锚定小菜单（最小宽 180），两项「分享…」（shareUp）、「存到「下载」」（download）；存好后行尾换成「已存到「下载」」，不可点。补三处：

- ① **已存状态带图标**。状态要图标 + 文字，灰字前加 12px 对勾（stroke 2，同 muted 色），不只放一行灰字。
- ② **Android 9 及以下**没有「存到「下载」」，菜单只剩一项就不弹了：点「存储」直接交系统分享面板。
- ③ **写入失败**给三段式，底部提示条：`没存进「下载」：手机剩余空间不够`，动作钮「改用分享」。其它原因同一格式，冒号后换原因。

另：走「分享…」之后行尾仍是「存储」，因为拿不到对方 App 是否真存了；重名时交给系统自动加「(1)」，行尾字面不变。
