## 一、实现侧的做法（先告知，不用改稿）

**不另画一套 Android 稿，复用《Umbra iOS 端.dc.html》与 iOS 设计交接包的 token。**

- 视觉层**完全沿用**：色板（亮 / 暗两套逐值搬，`UmbraTokens.kt` 与 iOS `UmbraTokens.swift` 同值）、字号字重、间距圆角、组件形制、图标（同一份 Lucide path 表，脚本从 iOS 生成）、文案与语气。
- 信息架构**完全沿用**：四个 Tab（聊天 / 提醒 / 工具 / 我）、导航树、各页区块顺序。
- 只有**平台交互层**按 Android 惯例替换，清单在第二节。现在是按「默认做法」那一列实现的。

## 二、要你裁定的平台差异（按顺序）

每条请回「照默认」或给出你的做法。

| # | iOS 稿 | Android 默认做法（已实现） | 为什么要换 |
|---|---|---|---|
| 1 | 底栏：浮动液态玻璃胶囊（左右 22 / 离底 26 / 高 64），果冻选中动效 | 不透明贴底底栏：card 底、顶部 1px borderSoft、高 58 + 系统手势条安全区；图标 23、选中橙色加粗描边 2.1、标签 10.5 | 液态玻璃是 iOS 26 系统私有渲染，Android 没有对等物；自绘磨砂在中低端机掉帧。Android 惯例是贴底不透明导航栏 |
| 2 | 根页 34/700 原生大标题，上滑 14–58px 小标题栏连续渐显，玻璃背景盖到小标题底 | 根页大标题 27/650 作为列表第一项随内容滚走；顶栏 54 高留空。推入页标题 17/600 放顶栏左侧（跟在返回箭头后） | Android 没有大标题折叠的系统件；M3 的 LargeTopAppBar 观感与 iOS 稿差得更远。要做渐显可以做，需要你给出 Android 上的规格 |
| 3 | 推入页左上「‹ 返回」+ 左缘拖 70px 返回 | 左上返回箭头（无文字）+ 系统返回手势 / 预测性返回动画 | Android 返回是系统级手势，App 不能也不该自己做左缘拖 |
| 4 | 左滑操作行：浮动胶囊按钮，果冻放大 0.55→1 | 系统 `SwipeToDismissBox`：左滑露出按钮，不滑到底自动执行；按钮形制沿用你的胶囊（44 高、图标+文字、danger / warning / 中性灰实底） | 果冻放大可做但成本高，先用系统件保证手势不和列表滚动打架 |
| 5 | 锚定玻璃小弹框（≤6 项从触发点展开） | M3 `DropdownMenu`，card 底不透明，从触发点展开 | 同第 1 条，玻璃在 Android 上不做 |
| 6 | 底部操作表、选择器：玻璃面板 | M3 `ModalBottomSheet`，bg 底，顶部圆角 26，带拖拽把手 | 同上；把手是 Android 惯例 |
| 7 | 确认弹窗：280 玻璃卡居中，双按钮分栏 | M3 `AlertDialog`：card 底、圆角 28、标题 17/600、正文 14 muted；按钮右对齐文字按钮（取消=正文色、确认=orangeText，破坏性=dangerText） | Android 惯例是右对齐文字按钮，分栏按钮在 Android 上显得像 iOS 移植 |
| 8 | 日期 / 时间：滚轮选择器 | 照 iOS `UmbraDateTimePanel` 自绘（月历 6×42 + 时分滚轮），走底部弹层 | 这条不换，只请你确认 Android 上也用它而不是 M3 原生日期选择器 |
| 9 | 灵动岛 / 锁屏 Live Activity（任务进度） | **Android 没有**。替代：任务执行中显示一条「进行中」常驻通知（Android 16 起用系统 Live Updates 进度样式），内容 = 任务名 + 当前步 + 进度 | 需要你给通知的文字结构（标题 / 正文 / 进度条文字各放什么） |
| 10 | 主屏小组件（小号任务、中号今日提醒） | Android 桌面小组件（Glance），尺寸 2×2、4×2，内容与 iOS 相同 | Android 小组件可以缩放，请给最小 / 默认尺寸下的排版，或确认照 iOS 两个尺寸 |
| 11 | 「小组件与轻点背面」说明页 | 轻点背面**Android 没有系统对应**，改为「小组件与桌面快捷方式」：讲两个小组件 + 长按 App 图标的快捷方式（记一笔、记灵感） | 页名与文案请你定 |
| 12 | AutoFill 面板（iOS 系统填充面板里列账号） | Android 自动填充：系统在输入框下方弹建议条，Umbra 只提供每条的标题 / 副标题文字；锁着时点建议条拉起一个解锁页 | 系统建议条样式由系统画，我们只能定文字；解锁页沿用保险箱锁屏态 |
| 13 | Face ID 图标与文案 | 「指纹 / 面部识别」统称「生物识别」，图标沿用 faceId 那颗 | 安卓机型不同，有的只有指纹；文案请你定 |
| 14 | toast 深色玻璃胶囊 | 深色不透明胶囊（toastGlass 88% 不透明度保留），距底 84（根页，让开底栏）/ 32（推入页） | 距离按 Android 底栏高度换算过 |

## 三、不用做的

- 不用为 Android 另出整套页面稿。
- 不用改 iOS 稿。
- 色板 / 字号 / 文案不用为 Android 调整（Android 照搬）。
